## 1. How the Tasks are Managed

We are using Jira and GitHub Project.

## 2. How to Access and Use the System

The system is currently under development. To access the project, clone the repository to your local machine and install the required frontend and backend dependencies.

The application consists of a **React Native** frontend and a **Go-based API** backend. After setup, the frontend and backend can be run locally for development and testing.

More detailed instructions for starting the application and using individual features will be added as development progresses.

## 3. Development Requirements

The main technologies currently used in the project are:

- **React Native** – used to develop the mobile application frontend.
- **Go** – used to implement the backend API.
- **Styled Components** – used for styling React Native components.
- **Gemini Flash** – used for AI-related functionality through Antigravity.
- **Git** – used for source control and collaboration.

Developers should have **Node.js** and a Node package manager such as **npm** installed for the React Native frontend, as well as **Go** installed for running and developing the backend API.

After cloning the repository, developers should install the required frontend dependencies and Go dependencies before running the application. Exact setup commands and required software versions will be added as the project configuration becomes finalized.

## 4. External Dependencies and Third-Party Software

The project currently uses the following external dependencies and services:

- **Gemini Flash** – provides AI functionality used by the application.
- **Antigravity** – used to access or integrate Gemini Flash functionality.
- **Styled Components** – third-party styling library used by the React Native frontend.
- **React Native libraries/packages** – additional packages may be used to support mobile application functionality.
- **Go packages** – external Go modules may be used by the backend API.

All software dependencies will be tracked through the appropriate project dependency files. Any required API keys, environment variables, or additional configuration instructions will be documented as they are introduced.
